# psiv-remake

Scoping for a modern remake of Phantasy Star IV.

- [Scope](docs/scope.md): what the remake is, what it is not, phases, and open questions

This repo holds planning documents and, later, tooling. It holds no script text, art, audio or other source material. Those stay in the rights holder's own storage until asset handling is agreed (see "Source material" in the scope).
