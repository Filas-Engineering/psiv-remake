# Published mechanics of the original game

This file lists what the fan community has published about the original game's rules, one row for each "To measure" item in [info-needed.md](../info-needed.md). Every fact here comes from community work: fan disassembly notes, fan patch readmes, speedrun and tool-assisted speedrun notes, fan wikis and FAQs. Treat every row as unconfirmed until it is checked against the rights holder's data or the reference build. Nothing here replaces the measurement methods in the spec.

Each fact is written in our own words. No script text and no content tables (enemy stats, item lists, shop lists, encounter tables, maps) were collected.

Many fan sites blocked automated reading (403, bot protection or paywall). For those, the facts come from search engine excerpts of the page and not from a full read. The Confidence column takes this into account, and the source list marks those pages.

Confidence:

- **High**: several independent sources agree, or the source is based on disassembly.
- **Medium**: one detailed source.
- **Low**: anecdotal, partial or conflicting.
- **None**: nothing published; needs measurement.

Technique damage is about (technique base + half the caster's Mental) x the target's element factor, minus target magic defense. Corrosion uses physical defense. A speedrun guide says there are 14 elements, and each enemy has a multiplier per element from immune through half, normal and 1.5x to double. One player found a technique doing less damage than the simple formula predicts.
