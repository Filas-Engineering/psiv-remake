# Saving and loading through the screens: a manual save from the field menu's Save page and an overwrite that asks
# first, the pause overlay's quit to the title (refused once at the confirm), the title's Load screen with the
# autosaves listed after the manual slot and a damaged one refused, then the manual save loaded. Last, the pause
# overlay over a battle's command menu, which holds the battle until it is resumed.
# With --window, the shot lines save screenshots under build/shots/ (run from bindings/); headless runs write nothing.

expect screen Title
press Enter
pressuntil Enter Field 800
cmd walk 7 4

# Saved to the second slot, then saved over after a Yes.
press M
press Right 3
expect state tab Save
press Down

press Enter

expect state selected manual_1 tidewater
expect state prompt none
press Enter
expect state prompt Overwrite manual_1?
press Enter
expect state prompt none
press Enter
press Up
press Enter
expect state prompt none
shot build/shots/save_page.png
press Escape
expect screen Field

# Quit to the title from the pause overlay: No keeps playing, Yes goes.
press P

expect state selected Resume
shot build/shots/pause_field.png

press Enter
expect state prompt Quit to the title? Play since the last save is lost.
shot build/shots/pause_quit.png
press Escape
expect screen Pause
press Enter
press Up
press Enter
expect screen Title
expect mode Title
