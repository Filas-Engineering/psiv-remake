# The small example layout set (make_layout_assets.py --small: 320x224, 16-pixel field cells, integer scaling, the bitmap
# font, on a copy of the test assets): the title; the arrival's narration and a speaker's line in the box the code puts
# at the bottom (the dialogue file's `box_h`, `box_margin` and `box_top`); the field's HUD card and hint line; the
# real-time glide in 16-pixel cells; the interaction prompt as a card under the target; click-to-walk to a cell; the
# reed path's whole-area picture; the lookout's comic panels in smaller margins (the panels file's params), each
# camera's cells 16 pixels times its zoom; Ember Steps' objects with pictures of their own. With --window the shot lines
# save screenshots under build/shots/small/ (run from bindings/).

cmd set text instant
expect screen Title
wait 2
expect state windows title/scene 0 0 320x224, title/box 12 52 184x108, title/corner 0 0 320x224, title/hint 0 212 320x12
shot build/shots/small/title.png
press Enter
waitstatehas 200 line The ferry bumps
expect state windows dialogue/banner 48 68 224x36, dialogue/box 4 140 312x70
expect state dialogue bottom
shot build/shots/small/dialogue_narration.png
press Enter
waitstatehas 300 line Mind the ropes
expect state windows dialogue/banner 48 54 224x36, dialogue/box 4 140 312x70
expect state dialogueoverlaps none
shot build/shots/small/dialogue_speaker.png
pressuntil Enter Field 400
dev encounters off
wait 20
expect state windows field/hud 2 2 116x24, field/toasts 0 0 320x224, field/hint 0 212 320x12
expect state overlaps none
shot build/shots/small/field.png
