# The example layout set's field menu (make_layout_assets.py): the pages listed down the left column, each page in the
# panel at the right with shorter rows; the status page's stats and abilities, the items with a target, the equipment
# comparison, a manual save, the codex and the options; then the quit confirm, the Load screen at the right with the
# save just written, and Bell Cove's save prompt. Each moment checks where the windows went. With --window the shot
# lines save screenshots in the working directory; headless runs write nothing.

cmd set text instant
expect screen Title
press Enter
pressuntil Enter Field 800
dev encounters off
cmd walk guide_front
press Up
