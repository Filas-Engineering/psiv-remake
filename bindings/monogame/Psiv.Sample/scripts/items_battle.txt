# The layout items' battle fields and models (make_items_assets.py), with --dev on the front data copy
# (make_front_data.py): the title's start state and its chosen entries with the erase list; the top-level step (fight, macro, run) before
# the members' commands; the command rows as a row of pictures that Left and Right walk (`command_axis` row); the list's kind and index
# sizing the command window; the acting member's slot; a name window only for a command chosen from a list; the
# members' status flags and the fallen flag on the strip; the enemies' status icons following the statuses table in the
# front layout and kept off it in the side layout; the top-level Run; and the result window paged two lines at a time.
# The `uifield` probe reads each field as the screen was last drawn with it. With --window the shot lines save
# screenshots under build/shots/items/ (run from bindings/).

cmd set text instant
expect screen Title
wait 3
expect state uifield.title.start true
expect state selected -
expect state windows title/scene 0 0 1280x720, title/press 430 300 420x120, title/corner 0 0 1280x720, title/hint 0 690 1280x30
shot build/shots/items/title_start.png
press Space
wait 2
expect state uifield.title.start false
expect state uifield.title.option_ids 6
