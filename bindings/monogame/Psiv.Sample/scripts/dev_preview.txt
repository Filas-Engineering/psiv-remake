# The panel and scene previewer, run with --dev. F12 opens its picker (events, and battle presentation entries). An event
# plays from a clean state: a new game in a scratch session that writes nothing, its opening event skipped, the party put
# beside the hook that starts the event, the event started at once. PageDown plays on to the next panel show and pauses,
# PageUp starts again and stops one panel earlier, End stops. A battle presentation entry plays one turn of synthetic
# typed events on dummy targets through BattleTimeline, with no session battle. The game being played is untouched and
# stays unmarked. With --window the shot lines save screenshots under build/shots/ (run from bindings/).

cmd set text instant
expect screen Title
press Enter
pressuntil Enter Field 400
press F12
expect state preview picker
wait 1
shot build/shots/dev_picker.png
press Right
wait 1
expect statehas selected attack
press Escape
expect state preview -
